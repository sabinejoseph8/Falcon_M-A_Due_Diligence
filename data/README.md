# Simulated data sources (fictional)

> Everything in this folder is FICTIONAL and was created for a portfolio demonstration. Talonfield Systems, Arbelion Industries, Norvale Retail Group and every other company, person, court case, article and number are invented. Any resemblance to real entities is coincidental.

Each folder stands in for one of the "tools" in the architecture:

| Folder | Simulates | Specialist subagent |
|---|---|---|
| `sec-filings/` | SEC Filing Search (EDGAR) | sec-filings-analyst |
| `news/` | News & Media API | news-media-analyst |
| `litigation/` | Litigation Database (court dockets) | litigation-analyst |
| `financials/` | Financial data (statements, KPIs, customer data) | financial-analyst |
| `deal-brief.md` | The deal team's brief and the Investment Committee's questions | lead agent |

Conventions: US$ millions unless stated. Fiscal year = calendar year. Negative numbers use a leading minus sign.
